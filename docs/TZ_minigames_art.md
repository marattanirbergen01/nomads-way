# Графика и анимация для мини-игр — задание для сессии «Анимация»

Дата: 2026-10-22. Заказчик — Марат. Механику и экраны сделало окно «Код» в ветке `experiment/minigames`
(описание — `docs/TZ_minigames.md`, данные — `content/games/s1.yaml`). Игры пока экспериментальные, в основную
версию не входят. Код рисует поле, точки, стрелки и шкалы сам; от тебя — картинки, которые делают игру
читаемой и красивой, и короткие звуки. Видео-роликов внутри игр не нужно.

Работай как с картами и наградами: кодом по слоям, свой конвейер в `motion/games/`, сначала финальная картинка — Марату.
Палитра и шрифт — как у анимированных карт и плашек (фон `#2A2019`, золото `#D9A441`/`#F1C453`, тёплый `#E08A4C`,
бирюза только для акцента; Golos Text / шрифт подписей карт). Казахские буквы ә ғ қ ң ө ұ ү һ і проверять глазами.

## 1. «Чистая» карта для пути кочевья — главное (без неё игра подсказывает ответ)
Сейчас фоном игры служит финальный кадр `map_s1e01_route`, а на нём уже нарисован пунктир Сыгнак → Шу.
- `map_s1e01_route_game.png` в `content/media/s1/maps/` — та же карта и геометрия кадра 1080×1890 (4:7),
  что `map_s1e01_route_kk.png`, но **без маршрута, без значка кочевья, без красной подписи «Шу · Қозыбасы»
  и без подписи «Сығанақ»**. Оставить: реки, горы (Каратау штриховкой), Балхаш, Иссык-Куль, заливки
  «Әбілқайыр иелігі» / «Моғолстан», крупно «ДЕШТІ ҚЫПШАҚ». Подписи областей — одной версией (kk), точки
  игры подписывает приложение на языке игрока.
- Координаты точек игры (доли кадра) — в `content/games/s1.yaml`, `route_shu.nodes`: Сыгнак (0,32; 0,39),
  Каратау (0,45; 0,47), Талас (0,58; 0,45), пески (0,40; 0,56), разведка Абулхаира (0,47; 0,31),
  Шу (0,735; 0,418). Если по настоящей географии точка должна стоять иначе — сдвинь в YAML и напиши «Коду».
- Пустые места под подписи точек (≈ 140 × 24 pt под каждой точкой) — без мелких деталей карты.

## 2. Схема поля боя для тактики (s1e02 sc100, Сыгнак 1510)
Сейчас расстановка лежит на художественном кадре битвы — точки на пёстрой картинке читаются плохо.
- `game_battle_syganaq_1510.png` в `content/media/s1/maps/` — 1080×1890, вид сверху, схема в стиле карт сезона:
  степь, стены Сыгнака сверху по центру, река/овраг для рельефа. **Без войск** — отряды рисует приложение.
  Верх и низ кадра — `#2A2019` (как у карт): нижние ~35 % закрывают кнопки манёвров.
- Отряды в `units` (доли кадра): Шайбани (0,50; 0,24), центр (0,50; 0,50), левое крыло (0,22; 0,46),
  правое (0,78; 0,46) — композиция должна оставить им место.

## 3. Значки (интерфейс, PNG с альфой, 128 × 128 px, круглые, в стиле портретов/плашек) → `content/media/s1/app/games/`
- Товары базара: `good_wheat` (мешок пшеницы), `good_cloth` (рулон ткани), `good_arrow` (наконечники стрел),
  `good_salt` (соль), `good_silk` (шёлк), `good_pot` (медный котёл), `cur_sheep` (овца — валюта).
- Точки пути: `node_camp` (стоянка/юрта), `node_river` (брод), `node_hill` (перевал), `node_enemy` (набег — всадник/знамя),
  `node_goal` (конец пути).
- Отряды тактики: `unit_ours` (знамя казахского войска, золото), `unit_enemy` (знамя Шайбани — белая чалма с красным верхом
  уже утверждена для портрета; на знамени — без лица, только цвет/символ).
- Залп: `volley_bow` (натянутый лук, вертикально, для шкалы 64 × 360 pt — можно отдельной вытянутой PNG), `volley_arrow`.

## 4. Звуки (wav 48 кГц, моно, ≤ 600 мс, пик ≈ −12 dBFS) → `content/media/s1/app/games/`
`game_step` (шаг каравана/копыто), `game_raid` (тревожный рог — попали на набег), `game_trade` (звон монеты/блеяние),
`game_deal` (хлопок по рукам), `game_horn` (боевой рог — старт манёвра), `game_bow` (тетива), `game_hit` (попадание),
`game_miss` (стрела в землю), `game_win`, `game_lose` (короткие, ≤ 1 с, домбра / дабыл как в плашках).

## 5. По желанию: эталон движения (как у плашек)
Короткая спецификация в мс и cubic-bezier: появление точки пути, рост пунктира между точками, «выстрел» стрелы
по шкале, проявление стрелок манёвра (сейчас 1,1 с easeInOut). Окно «Код» повторит её во Flutter.
Lottie/Rive не нужны.

## Проверка и сдача
- Карта и схема: 1080×1890, края `#2A2019`, уменьшенная до 390 px ширины — читается.
- Значки: на тёмном фоне `#22190F` и на кадре сцены видны, не сливаются.
- Источники: запись в `content/sources/media.yaml` по образцу карт; для схемы боя — на чём основана расстановка.
- Ничего не трогать в `app/`, `tools/`. Запись «Графика мини-игр сдана» в `docs/DECISIONS.md` и сообщение Марату.
