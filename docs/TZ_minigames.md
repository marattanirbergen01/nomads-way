# Мини-игры в сериях — ЭКСПЕРИМЕНТ (ветка `experiment/minigames`)

Статус: работает, покрыто тестами, в основную версию **не внесено** (решение Марата 2026-10-22: попробовать,
но не выкладывать). Сайт собирается только из `main`, эта ветка на него не влияет.

## Что есть
Четыре вида игр — один движок на вид, конкретные игры задаются данными (как выборы):

| kind | Что делает игрок | Исход |
|---|---|---|
| `route` | ведёт кочевье по точкам карты (только в соседнюю, можно отменить шаг) | через набег (`enemy`) — lose; дни ≤ лимита — win; иначе partial |
| `trade` | покупает товары за бюджет, «Келістік» | все нужды закрыты — win; ≥ половины — partial; иначе lose |
| `tactics` | выбирает манёвр, стрелки манёвра рисуются на поле | исход задан у манёвра |
| `volley` | стреляет, когда шкала напряжения в золотой полосе, N раундов | попаданий ≥ need — win; ≥ 1 — partial; 0 — lose |

Пример на сезон 1 — `content/games/s1.yaml`: путь кочевья (s1e01 sc031), базар Сыгнака (s1e02 sc010),
битва под Сыгнаком 1510 (s1e02 sc100) и залп там же — только если игрок выбрал роль лучника.

## Правила продукта (зашиты в код)
- Игра идёт после реплик сцены, до её вопросов. Вопросы ЕНТ в игру не встроены — правило №1 не нарушается.
- Проигрыш не блокирует сюжет; «Өткізу» в любой момент = partial.
- Исход ставит переменные (`set`, как у варианта выбора) → работают плашки «+N черта», `when`, `art_when`
  и перенос между сериями сезона. Ответ аватара (`reply`) показывается как обычная реплика.
- Вышли посреди игры — после возврата игра начинается заново с того же места.
- У каждой игры есть `source` из реестра (принцип «нет источника — нет в сборке»).

## Формат `content/games/<season>.yaml`
```yaml
<серия>:
  <сцена>:
    - id: route_shu            # уникален в серии
      kind: route | trade | tactics | volley
      source: tb06_ru#§…       # обязателен, id из sources/registry.yaml
      title:  { kk, ru }
      prompt: { kk, ru }       # задание игроку
      art: map_…               # необязательно: своя картинка (иначе кадр сцены); кладётся в бандл серии
      when: [{ var, op, value }]   # необязательно: условие запуска (op: >= > <= < == !=)
      outcomes:                # все три обязательны
        win:     { set: { trait: 1 }, reply: { kk, ru } }
        partial: { set: {},          reply: { kk, ru } }
        lose:    { set: { flag: 1 }, reply: { kk, ru } }
      # route
      start: <node>; goal: <node>; days_limit: 12
      view: [x0, y0, x1, y1]   # необязательно: увеличенный участок кадра; все точки внутри
      nodes: [{ id, x, y, label: {kk, ru}, kind: camp|river|hill|enemy, label_at: below|above|left|right }]   # x, y — доли кадра 4:7
      edges: [[a, b, дней], …]
      # trade
      budget: 10; currency: {kk, ru}
      goods: [{ id, price, label: {kk, ru}, icon? }]; needs: { <good>: сколько }
      # tactics
      units: [{ label: {kk, ru}, x, y, enemy? }]
      moves: [{ id, outcome: win|partial|lose, label: {kk, ru}, arrows: [[x1, y1, x2, y2], …] }]
      # volley
      rounds: 3; need: 2; period_ms: 1500; window: [0.85, 1.0]
```
Подписи с запятой — в кавычках: `{ kk: "А, Б", ru: "…" }`. Компилятор ловит лишние ключи.

Компилятор проверяет: сцена есть, id уникален, источник в реестре, тексты kk/ru, все три исхода;
`route` — точки и рёбра существуют и **победа достижима** (путь без набегов в лимит дней);
`trade` — нужды среди товаров и на них **хватает бюджета**; `tactics` — есть верный манёвр;
`volley` — окно внутри 0..1, `need ≤ rounds`.

## Код
- `app/lib/engine/games/game_spec.dart` — описания и движки (чистый Dart).
- `app/lib/features/games/game_screen.dart` — экран игры, четыре поля.
- `story_runner.dart` — событие `GameBreak`, `finishGame(исход)`, снимок с позицией игры.
- `story_screen.dart` — запуск игры, плашки и реплика после.
- `tools/bin/compile.dart` — `_games()`: проверка и вливание в `episode.json` (`scenes[].games`), картинки игр в бандл.
- Тесты: `test/engine/games_test.dart`, `test/widgets/game_screen_test.dart` (на настоящей сборке).
- `app/lib/dev_games.dart` — демо-запускалка всех игр (`flutter run -t lib/dev_games.dart`); в main не нести.

## Как внедрить в основную версию
1. Решение Марата и запись в `docs/DECISIONS.md`; «Контент» вычитывает тексты и источники `content/games/s1.yaml`,
   историк смотрит исходы (особенно тактику 1510).
2. Дождаться графики от «Анимации» (`docs/TZ_minigames_art.md`): без «чистой» карты путь кочевья подсказывает ответ —
   на финальном кадре анимированной карты уже нарисован маршрут.
3. Влить ветку: `git merge experiment/minigames` (без `lib/dev_games.dart`), прогнать `flutter test`, push в main —
   сайт соберётся сам. Отпечаток серий изменится: игроки посреди s1e01/s1e02 начнут серию заново.

## Известные ограничения
- Карты игр — PNG по 1,7–1,9 МБ: пакет серии растёт на ~1,7 МБ. Перед внедрением — пережать (jpg, как постеры).
- На маленьких экранах кнопка «Келістік» у базара ниже края — прокрутка (кнопки ↓ из `ScrollButtons` можно подключить).
