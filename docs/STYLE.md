# Стиль-байбл (черновик)

## Цель
Одна сильная иллюстрация на сцену. Игрок смотрит на неё, пока читает текст. Кадры должны быть узнаваемы в учебнике: степь, юрта, конь, оружие и одежда XV века — без фантазийных анахронизмов.

## Инструмент
Draw Things (macOS, Apple Silicon). Модель: SDXL (полный Flux на 16 ГБ не идёт; Flux Schnell квантованный — допустимо).

## Что фиксируем (заполнить после 20 эталонных кадров)
- Промпт-префикс: …
- Негативный промпт: …
- Палитра: …
- Соотношение сторон: 16:9 для сцен, 1:1 для карточек тем
- Seed-политика: seed записывается в `content/media/<season>/manifest.yaml` для каждого кадра

## Правила
- Ни одной картины современных художников «из интернета» — только свои генерации, Wikimedia Commons и общественное достояние.
- Каждый файл — запись в `content/sources/media.yaml`: происхождение, автор, лицензия. Нет записи — нет в сборке.
- Историк визирует арт так же, как текст: одежда, оружие, сбруя, интерьер юрты.
- Пока команда — один человек: генерация в Draw Things по промптам из `content/media/s1/prompts/`, отбор кадра, запись seed в manifest.
