# Окно «Код» — правила зоны `app/`

Flutter-клиент. Медиаплеер с машиной состояний, не игровой движок.

## Нельзя
- Редактировать `content/`. Если в контенте ошибка — записать в `docs/DECISIONS.md` или сообщить; править будет окно «Контент».
- Класть контент в `assets/`. Только иконки и шрифты. Всё остальное приходит бандлами.

## Архитектура
- `lib/engine/` — чистая логика без Flutter-импортов, покрыта тестами:
  - `story_runner.dart` — исполняет граф сцен, держит переменные
  - `quiz_runner.dart` — выдаёт вопросы, перемешивает варианты, считает балл
  - `scheduler.dart` — интервальное повторение (упрощённый SM-2)
  - `mastery.dart` — % готовности по темам
- `lib/data/` — модели (из `build/*/episode.json`, `questions.json`), локальное хранилище, загрузка бандлов
- `lib/features/` — экраны. Экран не содержит логики движка.
- Порядок сборки движков: story → quiz → scheduler → mastery. Каждый показывается людям отдельно.

## Три правила продукта, зашитые в код
1. Вопрос показывается только между сценами (после `quiz:` сцены), никогда внутри.
2. Неверный ответ не блокирует: разбор → в очередь повторения → дальше.
3. Экран сюжетного выбора и экран вопроса — разные виджеты с разной визуальной системой.

## Локализация
Все строки — `{kk, ru, en}`. Виджеты тестируются на kk как на самой длинной строке.
