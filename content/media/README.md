# Медиа

- `s1/manifest.yaml` — статусы и брифы иллюстраций. `pack.dart` берёт только `status: approved`.
- Исходники PNG кладутся рядом с манифестом: `s1/<id>.png`. Сырые итерации — в `s1/raw/` (в git не попадают).
- Инструмент по умолчанию — Draw Things (SDXL) локально. Seed и промпт записываются в манифест.
- Происхождение и лицензия каждого файла — `content/sources/media.yaml`. Нет записи — нет в сборке.
