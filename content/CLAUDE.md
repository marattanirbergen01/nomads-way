# Окно «Контент» — правила зоны

Здесь живут дерево тем, сценарии, вопросы, источники и медиа. Кода здесь нет.

## Нельзя
- Редактировать `app/`, `tools/`, `server/`. Если нужно изменить формат — запиши предложение в `docs/DECISIONS.md` и остановись; правку формата и компилятора делает окно «Код».
- Придумывать факты. Каждое `must_know`, каждый `source:` — ссылка на запись в `sources/registry.yaml`.
- Писать вопрос на факт, которого нет в `covers` сцены. Компилятор это отклонит.

## Порядок работы над серией
1. Убедиться, что нужные факты есть в `curriculum/ent_history.yaml` → `must_know`. Нет — добавить со ссылкой на источник.
2. Написать сцены в `episodes/<season>/<ep>.yaml`. Сначала kk, потом ru. `en` — позже.
3. В `covers` каждой сцены перечислить факты, которые в ней реально прозвучали.
4. Написать вопросы в `questions/<season>/<ep>.yaml`: на каждый факт минимум один, цель — три разной формулировки.
5. Неправильные варианты — типичные ошибки, а не случайные имена. Записать в `distractor_note`, какую путаницу ловим.
6. `explain` — 2–3 фразы, причина, а не только факт. Здесь происходит обучение.
7. Проверить: `dart run tools/compile.dart --check` (читать вывод можно, править компилятор — нельзя).

## Язык
- Казахский — оригинал. Русский — перевод. Строки kk длиннее — это норма, интерфейс подстроится.
- Имена реальных лиц: Керей, Жәнібек, Әбілқайыр, Есен-Бұға, Орыс хан (kk) / Керей, Жанибек, Абулхайр, Есен-Буга, Урус-хан (ru). Не смешивать варианты внутри одного языка.

## Достоверность
- Реальное событие, лицо, дата — только со ссылкой на источник.
- Вымышленный персонаж помечается `fiction: true` в `characters`. Его личная линия — вымысел, но он не может «знать» того, чего не было.
- Историк визирует серию целиком: `approved_by` в шапке серии. Без визы серия не публикуется.
