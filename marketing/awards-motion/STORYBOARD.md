# Nomad's Way — раскрытие награды · раскадровка

**Бриф.** Короткая (2–3 с) анимация получения награды в цветах приложения плюс один новый цвет.
Движение точное и плавное (ease-in-out), аккуратные трансформации и морфинг форм, мягкое свечение
без пересвета. Линии прорисовываются, сканируют и пульсируют. Без отражающего пола и лишних бликов.

**Формат.** 4 ролика (Мерген, Көш бастаған, Шежіреші, 7 күн қатар), 1080×1920 (как экран награды
в приложении), 2,6 с, 60 fps = 156 кадров, H.264 4:2:0, AAC 48 кГц.

**Палитра.** Земля #2A2019 / #1A1410, медаль #2F241B, золото #D9A441 / #F1C453 / #57472F, текст
#F4ECDF / #E8D9BD / #B8A68F. **Новый цвет — бирюза #4FA7A0 (светлая #86CFC6)**: бирюзовые изразцы
и орнаменты степи, холодный контрапункт к золоту. Роль: только скан и курсор проявления текста.

**Нить.** Фирменный золотой горизонт сворачивается в кольцо медали, бирюзовый скан «проверяет»
заслугу, внутренний круг морфится в знак, медаль подтверждается одним мягким импульсом.

## Таймлайн (одинаковый для всех наград)

| Время, с | Изображение | Звук |
|---|---|---|
| 0,00–0,42 | Горизонт прорисовывается из центра, края гаснут | воздушный тон |
| 0,12–0,60 | «ЖАҢА МАРАПАТ»: разрядка сходится 0,9 → 0,26 em | — |
| 0,32–0,92 | Середина линии поднимается, концы смыкаются внизу: линия → кольцо | мягкий свип, щелчок замыкания |
| 0,62–1,12 | Диск медали, внутреннее кольцо идёт навстречу | — |
| 0,90–1,42 | Внутренний круг (16 дуг) морфится в знак; бирюзовый скан снизу вверх доводит его до золота | шумовой скан вверх |
| 1,08–1,46 | Деталь: 20 делений (Мерген), караванный путь (Көш), 7 дуг-дней (7 күн) | тики / 7 нот домбры |
| 1,45 | Подтверждение: внешнее кольцо-импульс, мягкий подъём свечения | домбра D–A, колокольчик, удар |
| 1,36–2,36 | Название по буквам, описание kk и ru проявляется бирюзовым курсором | хвост аккорда |
| 2,36–2,60 | Читаемый кадр | затухание до тишины |

Камера всё время движется: dolly-in, небольшая дуга, крен −1,4° → 0,35°. Дальний план (сетка
дуг и меридианов) и передний (штрихи) в расфокусе дают параллакс. Motion blur — 5 субкадров
на быстрых фазах.

## Выбор приёма (варианты)
- Появление медали: **горизонт → кольцо** / точка-солнце растёт в кольцо / кольцо собирается из дуг / медаль проявляется сканом. Горизонт выбран: это фирменная линия приложения.
- Появление знака: **морфинг из внутреннего круга + скан** / прорисовка штрихов по одному / проявление маской. Морфинг выполняет требование брифа о трансформации форм.
- Подтверждение: **одно мягкое кольцо-импульс** / вспышка / частицы. Вспышку и частицы исключает бриф.
